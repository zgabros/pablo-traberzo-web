# Product

## Register

product

## Users
Site administrators (Pablo Traberzo and team). They use this interface to manage the content of the website (courses, news, hero section).

## Product Purpose
A CMS dashboard tailored for the pablo-traberzo-web website, allowing quick updates without editing code.

## Brand Personality
Professional, efficient, focused, utilitarian. 

## Anti-references
- Cluttered, over-engineered corporate dashboards.
- Playful or whimsical UIs that distract from data entry.
- Generic AI-looking dashboards with unnecessary graphs.

## Design Principles
- Data-entry first: forms should be fast and clear.
- High contrast: ensure text is readable for fast scanning.
- Action-oriented: primary actions (save, create) should be unmistakable.

## Accessibility & Inclusion
WCAG AA compliance for contrast and keyboard navigation, ensuring admin staff can use it with screen readers if necessary.
